# Portable Skill Repository Guidance

- This repository is public. Add only employer-neutral skills and examples.
- Never commit internal URLs, cloud account IDs, private repository names,
  employee identity maps, credentials, or organization-specific policy.
- Keep `README.md` inventory and provenance current when adding, removing, or
  renaming a skill.
- Preserve pinned upstream sources and applicable license notices.
- Keep one canonical editable copy of each skill. Organization-specific
  variants must use a distinct scoped name in their organization repository.
- Validate changed skill frontmatter, bundled scripts, and relevant tests before
  committing.
