# Kevin's Portable Skills

Canonical home for skills Kevin uses across employers and personal projects.
Everything here must be employer-neutral and safe to publish. Organization
policy, private operational context, internal URLs, account identifiers,
employee identity maps, and incident-derived conventions belong in the
corresponding work repository instead.

## Ownership rules

- Keep one editable canonical copy of each portable skill in this repository.
- Give organization-specific variants distinct names rather than forking a
  same-named installed skill.
- Preserve upstream URLs, pinned commits, and license notices for imports.
- Review every public change for employer names, private repository coordinates,
  account IDs, internal domains, credentials, and personal employee data.
